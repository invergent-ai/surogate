# Qwen3 LoRA

```bash
surogate sft examples/sft/qwen3/qwen3-lora-bf16.yaml
```

The [maintained config](../../../examples/sft/qwen3/qwen3-lora-bf16.yaml) trains a
rank-16 BF16-compute LoRA adapter on Romanian math instructions. See the
[training examples](../../../examples/training/README.md) for full fine-tuning,
adapter continuation, checkpoint resume, multi-GPU execution and monitoring.
